O problema nunca foi você

Quando algo é novo, a voz de dentro diz: “isso não é pra mim”.

Nós entendemos você. Isso não é culpa sua. Essa sensação tem nome: síndrome da impostora. Ela é mais comum do que parece.

75%

Fonte: KPMG, Women’s Leadership Summit Report (2020).

Na nossa visão, o que trava não é falta de capacidade. É falta de um ambiente onde errar seja permitido. Foi para criar esse ambiente que o PyStart existe.

Não. A gente não promete emprego, salário nem resultado. Prometemos aulas ao vivo, acolhimento e ferramentas (Python, Git, GitHub e LinkedIn) para você dar o primeiro passo. Para onde ir depois é uma decisão sua.
